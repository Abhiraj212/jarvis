# 🤖 Jarvis – Smart Web AI Assistant (Offline)

Jarvis is a **browser-based smart AI assistant** made using **HTML, CSS, and JavaScript**.  
It works **offline**, supports **voice input/output**, has **memory**, and runs directly on a **phone or laptop browser**.

No API. No server. No login. Fully free.

---

## 🚀 Features

- 🎤 Voice input (Speech Recognition)
- 🔊 Voice output (Text-to-Speech)
- 🧠 Long-term memory using LocalStorage
- 📝 Remembers notes, likes, dislikes, and facts
- 😊 Mood system (happy / sad / normal)
- 📷 Camera access with simple face greeting
- 💬 Smart chat replies (ChatGPT-style logic, no API)
- ⚡ Works offline
- 📱 Mobile & desktop compatible
- 🧩 Fully editable JavaScript brain

---

## 🛠️ Tech Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Web Speech API
- Web Camera API
- LocalStorage
